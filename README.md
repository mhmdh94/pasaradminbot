# 🤖 PasarVolumeBot

ربات تلگرام برای **خرید حجم اضافه** مخصوص پنل **پاسارگارد (PasarGuard)**

---

## ✨ امکانات

- فقط یک ادمین اصلی
- افزودن پنل پاسارگارد (لینک + یوزرنیم + پسورد)
- تعریف پلن‌های حجم (از ۵۰۰ گیگ به بالا)
- خرید حجم برای هر یوزرنیم داخل پنل
- پرداخت **کارت‌به‌کارت** + ارسال عکس رسید
- تأیید دستی توسط ادمین → افزودن خودکار حجم به کاربر در پنل
- بک‌آپ خودکار دیتابیس و ارسال به تلگرام
- اسکریپت نصب کامل (مثل میرزا)

---

## 📋 پیش‌نیاز

- سرور اوبونتو ۲۲ یا ۲۴ (تمیز پیشنهادی)
- دسترسی root
- توکن ربات از [@BotFather](https://t.me/BotFather)
- آیدی عددی ادمین (از [@userinfobot](https://t.me/userinfobot))

---

## 🚀 نصب روی سرور

### روش ۱: از گیت‌هاب خصوصی (پیشنهادی)

```bash
# کلون کردن ریپو (توکن شخصی گیت‌هاب خودت را جایگزین کن)
git clone https://<TOKEN>@github.com/<USERNAME>/PasarVolumeBot.git
cd PasarVolumeBot

# اجرای نصب
sudo bash install.sh
```

سپس گزینه **۱** را انتخاب کنید و اطلاعات خواسته شده را وارد کنید.

### روش ۲: آپلود دستی

1. فایل‌های پروژه را روی سرور آپلود کنید (مثلاً با `scp` یا SFTP)
2. وارد پوشه شوید و اجرا کنید:

```bash
sudo bash install.sh
```

## 🔧 دستورات بعد از نصب

| دستور | توضیح |
|-------|--------|
| `systemctl status pasarvolumebot` | وضعیت ربات |
| `systemctl restart pasarvolumebot` | ری‌استارت |
| `systemctl stop pasarvolumebot` | توقف |
| `journalctl -u pasarvolumebot -f` | مشاهده لاگ زنده |

---

## 📖 راهنمای استفاده بعد از نصب

1. ربات را در تلگرام استارت کنید (`/start`)
2. **مدیریت پنل‌ها** → افزودن پنل (آدرس + یوزرنیم + پسورد ادمین پنل)
3. **مدیریت پلن‌ها** → پلن‌های حجم را اضافه کنید (مثلاً ۵۰۰ گیگ، ۱ ترابایت و ...)
4. **تنظیمات کارت** → شماره کارت و نام صاحب کارت را تنظیم کنید
5. **خرید حجم** → پنل + پلن + یوزرنیم کاربر را انتخاب کنید → واریز → عکس رسید → تأیید

## 🗄 بک‌آپ

- از منوی ربات هم می‌توانید بک‌آپ دستی بگیرید.

## ⚠️ نکات مهم

- ربات فقط با آیدی ادمین کار می‌کند (دیگران پیام «دسترسی ندارید» می‌گیرند).
- حجم به صورت **اضافه** به حجم فعلی کاربر در پنل اضافه می‌شود.
- اگر کاربر حجم نامحدود داشته باشد، افزودن حجم ممکن نیست.
- برای گیت‌هاب خصوصی، از Personal Access Token استفاده کنید.
